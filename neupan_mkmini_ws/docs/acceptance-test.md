# 验收测试

每次测试均使用 `scripts/record_acceptance_run.sh <run-name>` 记录。

## 静态障碍

- 在同一条有标记的路线中执行十次。
- 成功条件：无接触，且终点误差不超过 `0.5 m`。
- 通过标准：至少 9/10 成功。

## 慢速动态横穿

- 真人测试前，先使用柔软替代障碍物。
- 执行十次低于正常步行速度的横穿测试。
- 绕行成功，或完全停车等待后继续行驶，均可判定为成功。
- 最小净空目标：`0.5 m`。
- 通过标准：至少 9/10 无接触。

## 故障注入

验证以下每种事件都会产生零速度输出：

1. 停止发布 NeuPAN 命令。
2. 停止发布底盘反馈。
3. 发布软件急停消息。
4. 触发物理急停。
5. 使用遥控器接管。
6. 停止 TF 或使其失效。

## 必须保存的证据

- 每轮测试的 rosbag。
- 每轮测试对应的 CSV 结果行。
- NeuPAN 输出频率。
- 最小观测净空。
- 最终目标误差。
- 失败原因与恢复操作。

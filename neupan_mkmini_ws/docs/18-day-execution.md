# 18 日执行手册

每天安排一小时学习、四小时实现与测试、一小时记录和决策。存在未解决的安全问题时，
禁止进入下一阶段。

| 天数 | 工作内容 | 当日退出条件 |
| --- | --- | --- |
| 1 | 导入固定版本依赖，运行 `check_neupan_runtime.py`，构建 Jazzy 工作区，审查安全与接口。 | 所有包完成构建；档位差异已记录。 |
| 2 | 完成架空轮 CAN、反馈、遥控、急停和超时测试。 | 确认 `D=4`；所有停车路径均通过。 |
| 3 | 启动 Mid-360，录制静止和运动参考 rosbag。 | PointCloud2 与 IMU 时间戳稳定。 |
| 4 | 配置 FAST-LIO2 外参与里程计。 | 里程计连续，静止漂移处于可接受范围。 |
| 5 | 调节点云切片和 SLAM Toolbox。 | 室内 `/scan`、`/map` 与 `map -> odom` 稳定。 |
| 6 | 运行 Nav2 基线，输出隔离到 `/nav2/baseline_cmd_vel`。 | 可生成目标和全局路径，且不会驱动 NeuPAN。 |
| 7 | 学习 DUNE、NRMP 与 Ackermann 模型；运行官方阿克曼仿真。 | 仿真无接口错误并到达目标。 |
| 8 | 训练并验证 MK-mini DUNE 几何模型；运行 `check_neupan_runtime.py --require-checkpoint`。 | 匹配的 checkpoint 通过仿真。 |
| 9 | 使用 rosbag 回放测试 NeuPAN 与兼容适配器。 | `/neupan/ackermann_cmd` 发布频率超过 10 Hz。 |
| 10 | 集成 SLAM、Nav2 路径与 NeuPAN。 | 若 SLAM 不稳定，记录决策并切换到 odom 滚动模式。 |
| 11 | 运行安全桥测试和架空轮端到端控制。 | 故障门控与命令超时通过。 |
| 12 | 首次无障碍落地路径跟踪。 | 完成十次低速启停，无不安全运动。 |
| 13 | 测试单个静态障碍、走廊和转弯场景。 | 静态测试至少 9/10 通过。 |
| 14 | 测试完整在线 SLAM 导航与重新规划。 | 修改目标和重规划不会绕过安全桥。 |
| 15 | 先测试柔软动态障碍物，再进行慢速真人横穿。 | 能可靠停车或绕行，无接触。 |
| 16 | 调节振荡、转向、预测时域、点云过滤和 CPU 耗时。 | NeuPAN 输出保持在 10 Hz 以上。 |
| 17 | 完整预演并注入故障；冻结版本与配置。 | 所有验收脚本和停车路径通过。 |
| 18 | 正式执行静态/动态验收并审查证据。 | 归档结果、rosbag、配置与未解决风险。 |

## 第 10 日降级规则

若在线 SLAM 在第 10 日仍无法维持稳定地图与 TF，应停止继续占用关键路径。
使用 FAST-LIO2 里程计与滚动 Nav2 costmap 完成 NeuPAN 动态障碍验证，并将在线 SLAM
保留为后续任务。
